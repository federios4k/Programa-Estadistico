Programa estadístico con la utilidad de calcular la media y la varianza tanto muestral como sus intervalos de confianza poblacional con tan solo ingresar una tabla de frecuencias.
El programa primero te pide ingresar el tipo de dato a ingresar en la primera columna, ya sea gramos, litros, etc. Para luego ingresar la cantidad y su frecuencia de aparición. Al terminar tan solo basta con escribir end para que el programa te muestre la tabla embellecida con el repositorio tabulate, el programa importará a excel la misma con los calculos ya hechos, y abajo un menu interactivo donde elegir las diferentes opciones para mostrar dentro del programa.

Entre las opciones se encuentran: 
    1. Calcular media poblacional
    2. Calcular varianza poblacional
    3. Calcular intervalo de confianza de la MEDIA
    4. Calcular intervalo de confianza de la VARIANZA
    5. Ingresar una nueva tabla
    6. Salir

En las cuales se utilizan las librerías para cálculo estadístico numpy y scipy.
